[Печатаем в терминале:]

```bash

  --name n8n \
```

- `-v ~/.n8n:/home/node/.n8n` - сохраняем настройки в папку
- `n8nio/n8n` - образ контейнера (скачивается из Docker Hub)

Копируем эту команду и вставляем в терминал. Нажимаем Enter."

## ТЕХНИЧЕСКИЕ ПРОБЛЕМЫ И РЕШЕНИЯ

**Проблема 1: Docker не запускается**
- Решение: Перезагрузить компьютер, переустановить Docker

**Проблема 2: n8n не запускается на localhost:5678**
- Решение: Порт уже занят. Использовать другой:
  ```bash
  docker run -p 5679:5678 n8nio/n8n
  ```

**Проблема 3: OpenAI API возвращает ошибку**
- Решение: Проверить API ключ, убедиться что он не скопирован неправильно

**Проблема 4: Workflow выполняется очень долго**
