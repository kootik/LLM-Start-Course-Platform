## Задание 2.1: Сравнительный анализ параметров генерации
**Сложность:** ⭐⭐
**Инструменты:** OpenAI API / Anthropic API

**Описание:**
Проведите серию экспериментов, чтобы понять влияние `temperature` и `top_p` на выходные данные модели.

1.  **Подготовка:**
    *   Выберите один сложный промпт (например, "Напиши креативную историю о роботе, который полюбил тостер" или "Объясни квантовую запутанность пятилетнему ребенку").
    *   Используйте модель `gpt-3.5-turbo` или `gpt-4o`.

2.  **Эксперимент:**
    *   Сгенерируйте ответ 3 раза для каждой комбинации параметров:
        *   `temperature=0.1`, `top_p=1.0` (Детерминированный)
        *   `temperature=0.8`, `top_p=1.0` (Сбалансированный)
        *   `temperature=1.5`, `top_p=1.0` (Хаотичный)
        *   `temperature=1.0`, `top_p=0.1` (Узкий выбор токенов)

3.  **Анализ:**
    *   Сравните ответы по критериям: связность, креативность, повторяемость.
    *   Запишите свои наблюдения: В каких случаях модель начинает "галлюцинировать"? Когда она выдает почти идентичные ответы?

## Задание 2.2: Строгая валидация JSON (Structured Output)
**Сложность:** ⭐⭐⭐
**Инструменты:** JavaScript/TypeScript, Zod (или Python Pydantic)

**Описание:**
LLM часто ошибаются в структуре JSON. Ваша задача — создать надежный валидатор.

1.  **Задача:**
    *   Напишите промпт, который просит LLM извлечь данные из текста резюме в JSON формате:
        ```json
        {
          "name": "String",
          "skills": ["String"],
          "experience_years": Number,
          "is_hired": Boolean
        }
        ```
2.  **Реализация:**
    *   Используйте библиотеку **Zod** (JS) или **Pydantic** (Python) для описания схемы.
    *   Напишите функцию-обертку, которая:
        1.  Вызывает LLM.
        2.  Парсит JSON.
        3.  Валидирует его через схему.
        4.  **Retry Logic:** Если валидация не прошла, функция должна автоматически отправить ошибку обратно в LLM и попросить исправить JSON (до 3-х попыток).

## Задание 2.3: Пайплайн очистки данных (Data Cleaning)
**Сложность:** ⭐⭐⭐
**Инструменты:** Python (Pandas) или n8n

**Описание:**
Подготовьте "грязный" датасет для файн-тюнинга (Fine-tuning) модели.

1.  **Данные:**
    *   Создайте или скачайте CSV файл (50-100 строк) с колонками `instruction`, `input`, `output`.
    *   Добавьте "шум": пустые строки, HTML-теги (`<br>`, `<div>`), дубликаты, слишком короткие ответы.

2.  **Пайплайн:**
    *   Напишите скрипт, который:
        1.  Удаляет дубликаты.
        2.  Очищает текст от HTML тегов (используйте Regex или `BeautifulSoup`).
        3.  Удаляет строки, где `output` короче 5 символов.
        4.  Форматирует данные в JSONL формат (требуемый для OpenAI Fine-tuning):
            ```json
            {"messages": [{"role": "user", "content": "..."}, {"role": "assistant", "content": "..."}]}
            ```

3.  **Результат:**
    *   Чистый файл `cleaned_dataset.jsonl`.
