### 1. Transformer Architecture [23]
**Для:** Лекция 1 (Основы Transformer)  
**Показывает:**
- Структура Transformer с энкодер-декодер слоями
- Multi-head attention механизм
- Feed-forward сети
- Positional encoding
- Data flow через стек слоёв

**Где использовать в лекции:**
- Слайд 3: "Что такое Transformer?"
- Слайд 5: "Архитектура Transformer"
- Практический урок 1: обзор перед n8n

**Интеграция в лекцию:**
```markdown
### Архитектура Transformer

[Здесь будет диаграмма Transformer Architecture]

Transformer состоит из:
1. **Encoder** (слева) - обрабатывает входные данные
2. **Decoder** (справа) - генерирует выходные данные
3. **Multi-head Attention** - каждый токен видит все остальные
4. **Feed-forward** - нелинейные преобразования
5. **Positional Encoding** - информация о позициях токенов
```

### 2. Token-by-Token Generation Process [24]
**Для:** Лекция 2 (Архитектура LLM)  
**Показывает:**
- Как LLM генерирует текст один токен за раз
- Процесс выбора следующего токена
- Softmax функция и вероятности
- Iterative loop генерации

**Где использовать:**
- Слайд 3: "Процесс генерации токен за токеном"
- Объяснение: "Как GPT-4 генерирует текст"

**Интеграция:**
```markdown
### Как работает генерация текста?

[Здесь будет диаграмма Token Generation]

1. Начальный промпт преобразуется в токены
2. Пропускается через Transformer (96 слоёв для GPT-4)
3. На выходе: 100,000 вероятностей для каждого токена
4. Выбирается токен (по вероятности или случайно)
5. Новый токен добавляется в контекст
6. Повтор для следующего токена

Это повторяется до конца ответа!
```

### 3. Temperature Effect on Distribution [25]
**Для:** Лекция 2 (Параметры генерации)  
**Показывает:**
- Три графика с разными температурами
- Как меняется распределение вероятностей
- Temperature 0.1 = острое (высокий пик)
- Temperature 0.7 = сбалансированное
- Temperature 1.2 = плоское (низкие пики)

**Где использовать:**
- Слайд 6: "Параметры генерации - Temperature"
- Визуализация эффекта параметра

**Интеграция:**
```markdown
### Параметр Temperature

[Здесь будет график Temperature Effect]

**Temperature = 0.1** (слева)
- Очень острое распределение
- Модель выбирает почти всегда максимальный токен
- Результат: детерминированный, скучный

**Temperature = 0.7** (в центре)
- Сбалансированное распределение  
- Модель выбирает случайно, но с учётом вероятностей
- Результат: хороший баланс

**Temperature = 1.2** (справа)
- Почти плоское распределение
- Модель выбирает почти случайно
- Результат: творческий, но может быть странным
```

### 6. Self-Attention Mechanism [28]
**Для:** Лекция 1 (Глубокое погружение в Transformer)  
**Показывает:**
- Как каждый токен видит все остальные
- Attention weights matrix (heatmap)
- Отношения между токенами
- Концентрация внимания

**Где использовать:**
- Слайд 7: "Как работает Attention?"
- Объяснение: "Самое важное в Transformer"

**Интеграция:**
```markdown
### Механизм Self-Attention

[Здесь будет диаграмма Attention Mechanism]

Что происходит:
1. Каждый токен создаёт Query (Q), Key (K), Value (V)
2. Для каждого токена вычисляется внимание ко ВСЕМ токенам
3. Высокий attention = "это важный токен"
4. Низкий attention = "это не важно"
5. Результат: взвешенная сумма всех токенов

Пример: слово "bank" обращает внимание на:
- Слова рядом (контекст)
- Слова в начале (роль)
- Похожие слова (смысл)
```
